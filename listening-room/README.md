# 잠시, 음악 · The Listening Room

Ian Chung 사이트 안에서 음악을 듣고 잠시 쉬어가는 몰입형 음악실입니다.

- `/listening-room/` 또는 `?hall=chamber`: 피아니스트가 있는 작은 체임버홀
- `?hall=vineyard`: 촛불과 오케스트라가 있는 빈야드홀
- 캐릭터 이동, 좌석 선택, 내 촛불 놓기, 쉬는 자리, 숨 고르기, 감상 마치기
- Web Audio로 합성한 기본 피아노 스케치와 빗소리
- YouTube 공식 플레이어, 직접 음원 URL, 로컬 MP3/WAV 재생

## 실행과 배포

빌드나 패키지 설치가 필요 없는 HTML/CSS/JavaScript 앱입니다. 저장소 루트에서 정적 HTTP 서버를 실행하고 `/listening-room/`을 열면 됩니다. GitHub Pages는 이 폴더를 그대로 제공합니다. 기본 음악은 입장 또는 재생 버튼을 누른 뒤 시작됩니다.

공간은 Canvas 2D에 직접 투영하는 3D 렌더러입니다. `space.js`와 `orchestra.js`가 각각 홀을 그리고, `venue.js`가 URL에 맞는 홀을 불러옵니다. 음악은 `audio.js`, 외부 음원은 `media.js`, 휴식 활동은 `rituals.js`와 `stillness.js`에서 처리합니다.

촛불 위치는 브라우저에 약 20분 보관되며 다른 방문자와 공유되지 않습니다. 로컬 음원 파일은 서버에 업로드되지 않습니다. YouTube를 연결하면 공식 영상 플레이어가 표시되며, 영상의 임베드 허용 여부에 따라 재생이 제한될 수 있습니다. 외부 음원 URL은 해당 서버의 접근 정책에 영향을 받습니다.

왼쪽 위 '잠시, 음악'을 누르면 이언정 사이트 홈으로 돌아갑니다.

체임버홀은 제목을 표시하지 않는 두 개의 AAC 녹음 파일을 음악실 폴더에서 순서대로 재생합니다. `chamber-music.js`가 곡 선택, 탐색, 일시정지 및 8초의 곡 사이 쉼을 관리합니다. 빈야드홀의 기본 피아노 스케치는 유지됩니다.

## 별빛 온실

`?hall=greenhouse`는 별과 오로라가 보이는 유리 온실입니다. 36개의 개인 테이블에 카세트 데크와 헤드폰, 무드등이 놓여 있습니다. 테이블을 눌러 앉거나 「나만의 테이블」에서 가까운 자리를 선택하면 헤드폰을 씁니다. 음악, 합성한 밤숲·파도·빗소리, 고요를 선택할 수 있고 헤드폰을 벗거나 자리를 떠나면 소리가 멈춥니다. `greenhouse.js`는 공간과 캐릭터를, `greenhouse-audio.js`는 테이블과 오디오를 관리합니다. 소리는 각자 고르고, 닉네임과 캐릭터·좌석 상태는 같은 홀의 방문자들과 공유됩니다.

빈야드홀은 `vineyard-01.m4a`부터 `vineyard-03.m4a`까지 세 녹음을 제목 없이 재생합니다. 체임버홀의 두 녹음과 같은 컨트롤러에서 홀별 재생 목록을 분리합니다.

## 함께 머무는 음악실

닉네임은 1~12자로 설정하고 같은 홀에서 중복되지 않게 확인합니다. 체임버홀은 54명, 다른 홀은 최대 24명이 머무는 소규모 공간을 기본으로 구성했습니다. 위치는 약 1초 간격으로 전송하고 화면에서는 부드럽게 보간합니다. 좌석은 서버의 고유 제약으로 한 명만 사용할 수 있으며, 퇴장하거나 연결이 90초 이상 끊기면 자동으로 비워집니다. 손인사·끄덕임·마음 표시는 약 4초만 유지됩니다.

체임버홀·빈야드홀은 「함께 듣기」에서 같은 프로그램 시각을 따릅니다. 곡 전환은 모두에게 적용되고 일시정지는 본인에게만 적용됩니다. 「혼자 듣기」를 선택하면 개인 재생 위치를 사용할 수 있습니다. 온실의 헤드폰 소리는 항상 개인별입니다. 닉네임은 브라우저에 저장하고, 접속용 토큰은 현재 탭에만 저장합니다. 서버는 이메일이나 계정 가입을 요구하지 않습니다.

`presence.js`는 입장·좌석·접속자·음악 동기화를 담당합니다. 별도의 Sites 서버는 공개 게스트 API와 D1을 사용하며, 기본 연결 주소는 `https://ian-listening-room-together.delap.chatgpt.site/api/presence`입니다. 서버는 자신의 임의 토큰으로만 위치를 수정하게 하고, 닉네임과 위치 등 필요한 공개 정보만 응답합니다.

`scene-engine.js`는 WebGL 깊이 버퍼로 건축·가구의 겹침을 처리하고, 걷기와 카메라에 충돌 검사를 적용합니다. WebGL을 사용할 수 없는 기기에서는 기존 Canvas 렌더러로 돌아갑니다. 체임버홀은 양옆과 천장을 확장했고, 캐릭터의 앉은 방향은 카메라 회전과 분리했습니다. 걷기 속도는 약 1.85m/s입니다. 좌석 이동은 가구를 통과하는 보간 대신 경로를 따라 걸어간 뒤 앉습니다.

별빛 청음실: 「누워서 별 보기」로 현재 자리의 음악을 유지하며 1인칭 밤하늘 감상. 아바타·이름표·이동 UI를 숨기고, 드래그로 둘러보며 일어나기/Esc로 원래 좌석과 시점을 복원합니다.

입구: hall 매개변수 없이 접속하면 실제 공간 스냅샷 3장과 공간 선택 카드가 먼저 표시됩니다. 카드는 전체 영역을 누를 수 있는 링크이며 선택 후 닉네임 화면으로 이동합니다. 각 입장 화면의 「다른 공간 고르기」로 돌아올 수 있습니다.

좌석 이동: 가구 충돌과 바닥 높이를 반영한 경로로 초당 1.85m씩 걸어간 후 0.65초 동안 몸을 돌려 앉습니다. 이동 도중 다른 좌석 선택과 수동 이동으로 취소할 수 있습니다. 빈야드 테라스는 계단 통로로 연결됩니다. 체임버홀은 더 높은 아치와 천창, 넓어진 측랑, 무대 중심의 은은한 조명으로 구성했습니다.

체임버홀 시점 안정화: 충돌 전 목표 카메라와 보정된 카메라를 분리하고, 벽·기둥만 카메라 충돌에 반영합니다. 멀어지는 줌은 천천히 복원합니다. 앞창을 작은 면으로 분할하고 바닥 선의 높이를 분리해 표시 간섭을 줄였습니다. 어두운 청회색 석재와 따뜻한 창빛을 두 렌더링 방식에 동일하게 적용합니다.

작은 쉼과 교류: 손인사·끄덕임은 아바타의 실제 동작으로 표현하고, 따뜻한 찻잔과 담요 펼치기는 앉아서 이용합니다. 함께 있는 이름에서 곡 추천을 부탁하면 당사자끼리만 보이는 쪽지로 연주 번호를 답할 수 있습니다. 요청은 5분 후 사라지며 추천곡 재생은 개인 감상으로 전환합니다. 녹음된 곡의 제목은 표시하지 않습니다.

입구는 은은한 황동빛의 어두운 카드로 구성합니다. 모든 아바타는 연속 음영의 곡면으로 그립니다. 체임버홀 54석, 빈야드홀의 넓은 기본 시야와 천장 바라보기를 제공합니다. 곡이 자연스럽게 끝나면 작은 합성 관객 박수가 나오며 수동 넘김에는 나오지 않습니다. 별빛 청음실은 입장 후 작은 밤 공기와 풀벌레 소리를 기본으로 재생하며 헤드폰과 별도로 켜기·끄기·음량 조절을 제공합니다. 고요와 전체 음소거는 밤 소리도 함께 멈춥니다.

체임버홀은 나를 포함한 54명 모두 공간에 표시하고, 가까운 12명의 동작은 자세히 그립니다. 먼 관객은 같은 연속 음영의 가벼운 곡면으로 표현하고 구면 정점은 캐시해 렌더링 계산을 줄입니다.
