Research checked 2026-11-05. 181.FM publishes listener stream URLs and describes use in a personal player on its Support page. Folk Alley provides links for other streaming media players. The Greek broadcaster offers MP3/AAC/FLAC live listening. HTTPS MP3 responses and audio bytes were verified for all seven primary endpoints.

Native audio connects the visitor directly to the broadcaster only after selecting a genre while seated. This site does not relay, record or redistribute audio files. Advertisements and station announcements remain intact. The UI shows the station and its official link, without song metadata. Availability, regional restrictions, ads and programming remain under each broadcaster's control.

At entry no station is selected and the old synthetic track list is inaccessible. Sitting opens the seven genre buttons. Changing genre cancels the previous connection. Pause, removing headphones, leaving the seat, finishing the visit and pagehide stop and release the connection. Streams have a 16-second connection timeout, MP3/AAC format fallback where provided, an explicit retry and a link to the broadcaster. Small night air/crickets remain independent.

The existing private recommendation API supports three indices in this room, which are mapped to classical, pop and new age radio. All seven categories are available at the table. No backend or schema changes are required.

Christmas Classics uses the official HTTPS xtraditional MP3 stream, with AAC format fallback. The conservatory holiday scenery is native 3D geometry, with collision bounds for the tree and hearth and reduced-motion aware fire animation.

Jazz replacement (2026-11-05): The Jazz Groove Mix 1 replaces 181.FM Jazz Mix. The station founder publishes free player stream URLs at https://community.roonlabs.com/t/jazz-groove-org/109577 . The official web player uses radio.streamthejazzgroove.com. Both the HTTPS west MP3 listener stream and Mix 1 free fallback returned HTTP 200 and audio bytes. Live programming remains station-controlled.
